# Collage Studio

สร้างคอลลาจจากรูปกลุ่ม — ดาวน์โหลดได้จากเว็บ หรือส่งเข้ากลุ่ม LINE ผ่าน LIFF

SvelteKit ตัวเดียว deploy บน Vercel เรนเดอร์ด้วย `<canvas>` ในเบราว์เซอร์

```bash
bun install
bun run dev        # http://localhost:5173
bun run check
bun run build
```

รายละเอียดสถาปัตยกรรม คำสั่ง และ gotcha ทั้งหมดอยู่ที่ [`../AGENTS.md`](../AGENTS.md)
